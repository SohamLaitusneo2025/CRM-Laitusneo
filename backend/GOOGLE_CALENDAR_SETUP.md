# Google Calendar API Setup Guide

This guide will help you set up real Google Meet meeting creation using the `laitusneotechnologies@gmail.com` account.

## Prerequisites

- Gmail account: `laitusneotechnologies@gmail.com`
- Access to Google Cloud Console
- Python environment with required packages installed

## Step-by-Step Setup

### 1. Create Google Cloud Project

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Click "Select a project" → "New Project"
3. Name your project (e.g., "LaitusNeo CRM")
4. Click "Create"

### 2. Enable Google Calendar API

1. In the Google Cloud Console, go to "APIs & Services" → "Library"
2. Search for "Google Calendar API"
3. Click on "Google Calendar API"
4. Click "Enable"

### 3. Create OAuth 2.0 Credentials

1. Go to "APIs & Services" → "Credentials"
2. Click "Create Credentials" → "OAuth 2.0 Client ID"
3. If prompted, configure the OAuth consent screen:
   - Choose "External" user type
   - Fill in required fields (App name: "LaitusNeo CRM")
   - Add your email as a test user
4. For Application type, choose "Desktop application"
5. Name it "LaitusNeo CRM Desktop"
6. Click "Create"
7. Download the JSON file
8. Rename it to `credentials.json`
9. Place it in the `backend` folder

### 4. Run the Setup Script

```bash
cd backend
python setup_google_calendar.py
```

This will:
- Open a browser for authentication
- Log in with `laitusneotechnologies@gmail.com`
- Save authentication tokens
- Test the API connection

### 5. Test the Integration

After setup, the system will:
- Create real Google Meet meetings
- Add them to the Google Calendar
- Send email invitations automatically
- Generate working Google Meet links

## Troubleshooting

### Common Issues

1. **"credentials.json not found"**
   - Make sure you downloaded and renamed the OAuth2 credentials file
   - Place it in the `backend` folder

2. **"Access blocked" during authentication**
   - Make sure you added your email as a test user in OAuth consent screen
   - Check that the app is in "Testing" mode

3. **"API not enabled"**
   - Go to Google Cloud Console → APIs & Services → Library
   - Search for "Google Calendar API" and enable it

4. **"Invalid credentials"**
   - Delete `token.json` and run the setup script again
   - Make sure you're using the correct Gmail account

### File Structure

After setup, you should have:
```
backend/
├── credentials.json          # OAuth2 credentials (from Google Cloud Console)
├── token.json               # Authentication tokens (generated by setup)
├── google_calendar_oauth.py # Google Calendar integration
└── setup_google_calendar.py # Setup script
```
